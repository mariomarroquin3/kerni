# Questions to ask Kerni tomorrow

## Request
A short PDF with the questions that can be asked to Kerni the next day.

## Decisions
- Two pages in Spanish: a pre-flight checklist, eleven questions in a suggested order with what should happen and whether each one uses the model, what Kerni does not do yet, and what to do if something fails.
- Questions are grouped by cost: three need no model (disk percentage, the metrics from the two-finger menu, heavy files), the others use the model and the knowledge base.
- The PDF is honest about what was proven: only the RAM questions were tried end to end with the real model; the search was checked for the diagnostic-lights, ports and battery questions; the memory question was not tried live.
- It warns about the Gemini free tier (about 20 requests a day per model, each model question costs 1 to 3), so nobody rehearses with the model on the same day.

## Verification
- Rendered and checked page by page (2 pages). The claims come from the repository state and the real runs of this session.
