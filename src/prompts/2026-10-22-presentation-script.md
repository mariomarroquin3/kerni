# Presentation script (PDF)

## Request
A PDF with what six people will explain and show about the project. The live demo goes last and is assigned to a single person.

## Decisions
- Six blocks with placeholder names (Persona 1 to 6) to be replaced by the team: problem, character and experience, architecture, safety, memory and RAG, and the live demo (last, one person).
- Suggested times (about 20 minutes) are a proposal, not a constraint.
- The demo script separates steps that need nothing external (1 to 3), a model key (4) and Supabase with an indexed knowledge base (5 and 6), and has a plan B. It says not to promise anything that was not tried the same day.
- Written in Spanish because it is a speaking script for the audience; the file is `docs/guion_presentacion_kerni.pdf`.

## Verification
- Rendered and checked page by page (6 pages). Claims about the project were taken from the repository state; memory and RAG are flagged as not yet run against real Supabase.
