# Landing update after the v0.1.0 release

## Request
Publish v0.1.0, then review the landing page (rendered at 375, 768 and 1440 px) and apply the findings. Also run a local release build, because Kerni takes long to compile when started from the launcher.

## Decisions
- Hero label "Versión de prueba 0.1" became "Primera versión · 0.1.0"; the note under the button now says version, size and Windows requirement.
- The download button and step 1 point straight to `Kerni_0.1.0_x64-setup.exe`. Trade-off: the link must be updated on each release (documented in `landing/README.md`). "Otras versiones" and the `.msi` mention keep pointing to the releases page.
- On phones the text and the button now come before the mascot, so the download is visible without scrolling (button bottom at 561 px of 812).
- Open Graph and Twitter card tags added, with absolute URLs under the GitHub Pages address.
- Menu entry "Cómo te protege" shortened to "Protección".
- The speech bubble in the hero is labelled "Ejemplo de lo que dice Kerni". A real screenshot was not used: the app window is transparent, so a capture in the browser demo shows it on a white background.
- Nothing about the Windows Credential Manager was changed: it is still not built, so "Próximamente" stays.

## Verification
- Rendered at 375 px (button visible, no horizontal scroll), 768 px and 1440 px (two columns, no horizontal scroll). Text contrast measured in light mode: 7.3:1 at the lowest.
- The direct download link answers 200.
- Release build compiled with `npm run build -- --no-bundle` (output in the shared target folder).
